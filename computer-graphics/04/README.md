# Занятие 4. Отсечение отрезков алгоритмом Коэна–Сазерленда

## 1. Как запустить программу?
Открыть страницу по адресу GitHub Pages. Ввести координаты окна и отрезка,
нажать «Построить».

## 2. Какое окно использовалось в тестах?
Использовалось окно: xmin = 10, ymin = 5, xmax = 30, ymax = 20.

## 3. Соглашение о четырёх битах кода
- 0001 LEFT   — x < xmin
- 0010 RIGHT  — x > xmax
- 0100 BOTTOM — y > ymax
- 1000 TOP    — y < ymin

## 4. Результаты обязательных тестов

Окно: xmin = 10, ymin = 5, xmax = 30, ymax = 20.

| Случай | Отрезок | Коды A/B | Результат |
|---|---|---|---|
| Полностью внутри | (15,10)–(25,15) | 0000 / 0000 | ACCEPT сразу |
| Полностью слева | (2,10)–(5,15) | 0001 / 0001 | REJECT сразу |
| Полностью сверху | (15,2)–(25,3) | 1000 / 1000 | REJECT сразу |
| Одна граница | (5,10)–(20,15) | 0001 / 0000 | пересечение LEFT -> ACCEPT |
| Две противоположные | (5,10)–(35,15) | 0001 / 0010 | пересечение LEFT -> RIGHT -> ACCEPT |
| Через угол | (5,2)–(15,10) | 1001 / 0000 | пересечение TOP -> LEFT -> ACCEPT |
| Вертикальный | (20,2)–(20,25) | 1000 / 0100 | пересечение TOP -> BOTTOM -> ACCEPT |
| Горизонтальный | (5,10)–(35,10) | 0001 / 0010 | пересечение LEFT -> RIGHT -> ACCEPT |
| Обе снаружи, проходит через окно | (5,2)–(35,25) | 1001 / 0110 | TOP -> LEFT -> BOTTOM -> ACCEPT |

## 5. Результаты эксперимента со случайными отрезками
Пять прогонов по 200 случайных отрезков в логической области 40×30, окно 10,5–30,20:

| Прогон | Принято | Отсечено | Отброшено |
|---|---|---|---|
| 1 | 13 | 147 | 40 |
| 2 | 14 | 132 | 54 |
| 3 | 10 | 133 | 57 |
| 4 | 11 | 132 | 57 |
| 5 | 12 | 125 | 63 |

Средние значения: ~12 принято (6%), ~134 отсечено (67%), ~54 отброшено (27%).

Примерно **треть отрезков (~33%)** алгоритм обработал только по битовым кодам,
без вычисления точек пересечения — быстрый ACCEPT или REJECT. Остальные две трети
потребовали хотя бы одного пересечения с границей. При этом даже в этой трети многие
отрезки после первого пересечения отбрасываются через REJECT — потому что новая точка
попадает в общую с другой точкой внешнюю полуплоскость.
