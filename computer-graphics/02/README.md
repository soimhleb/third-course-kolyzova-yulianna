# Занятие 2. Алгоритм Брезенхема для отрезка

1. **Чем идея Брезенхема отличается от ЦДА?**
   ЦДА прибавляет вещественные приращения `dx/n` и `dy/n` и округляет
   результат. Брезенхем хранит одну накопленную ошибку `error` и по ней
   решает, сдвигать ли вторую координату. Используются операции сложения, вычитания и
   сравнения.

2. **Для чего используется переменная `error`?**
   Она накапливает отклонение текущего растрового пикселя от идеальной
   математической линии. Начальное значение `dx - dy` меняется на `±dy` / `±dx` в зависимости от того, какая
   координата сдвинулась. По её значению выбирается следующий пиксель.

3. **Зачем нужны `sx` и `sy`?**
   Они задают направление движения по каждой оси: `+1` - вправо/вниз,
   `-1` - влево/вверх. Благодаря им один и тот же код работает для отрезков
   в любую сторону.

4. **Почему две проверки нельзя бездумно заменить на if…else?**
   На шаге могут измениться обе координаты одновременно (на диагональном шаге).
   Если написать `if … else`, вторая проверка не выполнится, и такие шаги
   будут пропущены. Линия получится неверной.

5. **На каких входных данных вы обязательно проверяли программу?**
   - горизонтальный: (2, 5) - (20, 5)
   - вертикальный: (7, 2) - (7, 20)
   - пологий: (2, 2) - (20, 8)
   - крутой: (3, 2) - (7, 25)
   - обратный: (20, 8) - (2, 3)
   - одна точка: (10, 10) - (10, 10)
   - расхождение алгоритмов: (2, 2) - (8, 5)

6. **Совпали ли наборы пикселей ЦДА и Брезенхема во всех примерах?**
   На большинстве отрезков наборы совпали. Однако на (2, 2) - (8, 5) наборы отличаются в трёх точках по причине того, что ЦДА округляет вещественную координату,
   а Брезенхем выбирает пиксель по накопленной ошибке.
