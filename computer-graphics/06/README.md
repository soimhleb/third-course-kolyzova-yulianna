# Занятие 6. Отсечение многоугольников: алгоритм Сазерленда–Ходжмана

## Способ задания многоугольника
Исходный многоугольник задан в коде `app.js` в виде массива вершин (объектов с координатами `x` и `y`). 
Для проверки используется невыпуклая фигура в форме буквы «L»:
```javascript
const testPolygon = [
  { x: 5, y: 5 }, { x: 25, y: 5 }, { x: 25, y: 15 }, 
  { x: 35, y: 15 }, { x: 35, y: 25 }, { x: 5, y: 25 }
];
```

## Параметры окна
Окно отсечения задается через поля ввода в интерфейсе. Координаты по умолчанию: 
`xmin = 10`, `xmax = 30`, `ymin = 5`, `ymax = 20`.
Программа проверяет корректность ввода: если `xmin >= xmax` или `ymin >= ymax`, выводится сообщение об ошибке.

## Таблица четырёх переходов
Для каждого ребра `S → P` (от предыдущей вершины к текущей) относительно текущей границы окна алгоритм применяет следующие правила:

| Положение S | Положение P | Что добавляется в выходной массив |
| :--- | :--- | :--- |
| inside | inside | только вершина P |
| inside | outside | только точка пересечения с границей |
| outside | inside | точка пересечения с границей, затем вершина P |
| outside | outside | ничего не добавляется |

## Формулы пересечения
Для вычисления координат точки пересечения ребра с границей используется параметрическое уравнение отрезка:
`x = x1 + t(x2 - x1)`
`y = y1 + t(y2 - y1)`

*   Для **вертикальной границы** `x = xBoundary`:
    `t = (xBoundary - x1) / (x2 - x1)`
    `y = y1 + t * (y2 - y1)`

*   Для **горизонтальной границы** `y = yBoundary`:
    `t = (yBoundary - y1) / (y2 - y1)`
    `x = x1 + t * (x2 - x1)`

## Промежуточные списки вершин (Тест 2: окно 15, 20, 15, 20)
В этом тесте окно полностью лежит внутри исходного многоугольника.
*   **Исходный (6):** (5, 5), (25, 5), (25, 15), (35, 15), (35, 25), (5, 25)
*   **После LEFT (6):** (15, 5), (25, 5), (25, 15), (35, 15), (35, 25), (15, 25)
*   **После RIGHT (4):** (15, 5), (20, 5), (20, 25), (15, 25)
*   **После TOP (4):** (15, 15), (20, 15), (20, 25), (15, 25)
*   **После BOTTOM (4):** (15, 20), (15, 15), (20, 15), (20, 20)
*В результате многоугольник приобрел форму прямоугольного окна.*


## Один ручной расчёт
Возьмем ребро, идущее из точки **S = (5, 25)** в точку **P = (5, 5)**. 
Отсекаем по **нижней границе (BOTTOM)**: `y = 20`.
*   Точка S(5, 25) находится **снаружи** (т.к. 25 > 20).
*   Точка P(5, 5) находится **внутри** (т.к. 5 <= 20).
*   Это переход `outside → inside`.
*   Находим параметр `t = (20 - 25) / (5 - 25) = -5 / -20 = 0.25`.
*   Находим координату `x = 5 + 0.25 * (5 - 5) = 5`.
*   Точка пересечения: **(5, 20)**.
*   В выходной массив добавляются две точки: точка пересечения **(5, 20)** и внутренняя вершина **P(5, 5)**.
