# Занятие 1. Растровая графика, пиксели и алгоритм ЦДА

## Ответы на вопросы

1. **Что такое растеризация?**
   Это процесс преобразования непрерывного геометрического объекта (например,
   математического отрезка) в набор дискретных пикселей растра, которые
   наилучшим образом изображают этот объект.

2. **Зачем в ЦДА выбирается max(|dx|, |dy|)?**
   Чтобы за один шаг координаты не изменялись больше чем на один пиксель ни по
   одной оси. Если взять меньшее из значений, то на крутых или пологих отрезках
   за шаг можно перескочить сразу несколько пикселей, и тогда линия получится с дырками.
   `max` задаёт количество шагов так, что шаг по обеим осям не превышает 1.

3. **Почему координаты приходится округлять?**
   Потому что приращения `xStep` и `yStep` - дробные, и после каждого прибавления
   координаты становятся вещественными. Пиксель же имеет целые координаты,
   поэтому `Math.round` выбирает ближайший пиксель растра.

4. **Что произойдёт, если начало и конец отрезка совпадают?**
   `dx = 0` и `dy = 0`, значит `steps = max(0, 0) = 0`. Деление на ноль недопустимо,
   поэтому этот случай обрабатывается отдельно: рисуется один пиксель в данной
   точке.

5. **Какие недостатки ЦДА вы заметили?**
   Алгоритм использует вещественные числа, содержит деление и округление на
   каждом шаге, а из-за накопления погрешности при округлении линия может
   получаться неравномерной толщины.
