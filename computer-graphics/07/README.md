# Занятие 7. Редактор геометрических преобразований

## 1. Команды или порядок запуска
Установка библиотек не требуется. Откройте файл `index.html` в браузере или перейдите по ссылке GitHub Pages.

## 2. Определения матриц T, R, S
Используются матрицы 3×3 (однородные координаты):
*   **Матрица переноса T(tx, ty):**
    `[1, 0, tx]`
    `[0, 1, ty]`
    `[0, 0, 1]`
*   **Матрица масштабирования S(sx, sy):**
    `[sx, 0, 0]`
    `[0, sy, 0]`
    `[0,  0, 1]`
*   **Матрица поворота R(θ):**
    `[cosθ, -sinθ, 0]`
    `[sinθ,  cosθ, 0]`
    `[0,     0,    1]`

## 3. Каким образом выполнено умножение матриц
Умножение реализовано функцией `multiplyMatrices(a, b)`. 
Каждый элемент результирующей матрицы `C` вычисляется как скалярное произведение строки `i` матрицы `A` и столбца `j` матрицы `B`:
`C[i][j] = A[i][0]*B[0][j] + A[i][1]*B[1][j] + A[i][2]*B[2][j]`.
Для этого используется тройной цикл (`for i... for j... for k...`).

## 4. Какая точка используется как центр
В интерфейсе можно задать произвольный центр `(cx, cy)` (по умолчанию 20, 15). 
Чтобы повернуть или масштабировать фигуру вокруг этой точки, используется композиция матриц:
`M_transform = T(cx, cy) * R * S * T(-cx, -cy)`.
То есть мысленно центр переносится в начало координат (0,0), выполняется поворот/масштаб, и затем центр возвращается на место. Визуально центр отмечен синим крестиком на Canvas.

## 5. Таблица ручного расчёта
**Пример:** поворот точки `P(10, 10)` на угол `90°` вокруг центра `(0, 0)`.
*   `cos(90°) = 0`, `sin(90°) = 1`.
*   `x' = 10 * 0 - 10 * 1 = -10`.
*   `y' = 10 * 1 + 10 * 0 = 10`.

| Вершина | x исходный | y исходный | x новый | y новый |
| :--- | :--- | :--- | :--- | :--- |
| P0 | 10 | 10 | -10 | 10 |

## 6. Результаты двух разных порядков преобразований
Возьмем параметры: `tx = 30, ty = 0, angle = 90°`, центр `(0,0)`.
*   **Режим А (Сначала поворот, потом перенос):** 
    Формула: `M = T * R`. Точка `(10, 10)` сначала поворачивается на 90° и становится `(-10, 10)`, а затем переносится на +30 по X. Итог: **`(20, 10)`**.
*   **Режим Б (Сначала перенос, потом поворот):** 
    Формула: `M = R * T`. Точка `(10, 10)` сначала переносится на +30 по X и становится `(40, 10)`, а затем вся конструкция поворачивается на 90°. Итог: **`(-10, 40)`**.

## 7. Почему результаты отличаются
Результаты отличаются, потому что **умножение матриц некоммутативно** (`A * B ≠ B * A`). 
В режиме А перенос применяется к уже повернутой системе координат. 
В режиме Б перенос применяется к исходной системе, а затем вся система (вместе с переносом) поворачивается. Порядок применения матриц имеет значение.
