# Занятие 1. Счётчик

1. **Где хранится состояние программы?**
   В одной переменной `value` в файле `app.js`.

2. **Какая функция обновляет интерфейс?**
   Функция `render()`. Она берёт текущее значение `value` и записывает его в DOM-элементы `#value` и `#message`.

3. **Какие события обрабатываются?**
   Событие `click` на трёх кнопках: `#increase`, `#decrease`, `#reset`.

4. **Что произойдёт, если изменить `value`, но не вызвать `render()`?**
   Внутреннее состояние программы изменится, но пользователь этого не увидит: текст на странице останется прежним. DOM обновляется только тогда, когда мы явно изменяем его свойства (например, `textContent`). Именно это делает `render()`.
